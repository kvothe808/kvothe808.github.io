# Cau d'Alcoi

El Cau, el joc de cartes de les filaes d'Alcoi: juegas con tu compañera contra dos rivales (bots).

- Se usa desde el navegador o instalada en el móvil.
- Funciona sin conexión después de abrirla una vez.
- La partida y los ajustes se guardan solo en el dispositivo.
- Baraja clásica: «Naipes Libres» (baraja española de licencia libre).

**Actualizar la app:** sustituir `index.html` y cambiar `VERSION` en `sw.js`.
